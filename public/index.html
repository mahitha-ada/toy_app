The big picture

Text goes in → a small neural network (running on ONNX Runtime via transformers.js) turns it into a 384-number vector → similar meanings end up close together. Below is the built-in corpus, embedded and visualized two ways. Rotate the 3-D map; hover any point.

"a fluffy cat"→ tokenizer→ MiniLM (ONNX)→ mean-pool + normalize→ [0.02, -0.07, … ] (384-D)

② What the model actually reads

Models don't see words — they see sub-word tokens mapped to integer IDs. Long/rare words get split into pieces (## = continuation).

③ One sentence → 384 numbers

Every input becomes the same fixed-length vector. Here is that vector drawn as a bar chart and a heat strip. Change the text and watch the fingerprint change.

⑤ Semantic search (a vector DB in disguise)

Embed documents once, embed the query, sort by cosine similarity. No keyword matching — results come back by meaning. Searches the built-in corpus.

⑥ See the whole space

PCA squashes 384-D down to 2-D/3-D so you can see clusters. Use the built-in corpus or paste your own sentences (one per line) to map them.
